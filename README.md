# Messaging App

A full-stack direct-messaging application built from scratch with Next.js,
TypeScript, PostgreSQL, Prisma, Auth.js, React Query, and Zod.

The backend and application layers are established. The current interface is a
functional test harness and is the next major area of work. The planned
presentation pass will use WhatsApp as interaction inspiration while creating
an original visual system, then real-time delivery will be added separately.

The complete documentation set covers the product, architecture, backend,
frontend, optimistic behavior, real-time plan, engineering practices, current
gaps, and phased roadmap. Start with
[docs/README.md](./docs/README.md).
